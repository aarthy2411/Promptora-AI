#  Promptora AI — Explore the Power of Prompt Engineering

## About the Project

**Promptora AI** is a Python-based application designed to explore and experiment with different prompt engineering techniques using Generative AI.

The application allows users to enter a task, select a prompting technique, customize generation settings, and receive an AI-generated response through an interactive Streamlit interface.

Instead of using the same prompt structure for every task, Promptora AI demonstrates how different prompting strategies can guide an AI model to produce responses in different ways.To run Promptora AI on your computer, follow the installation instructions and start the Streamlit application.

Local URL: http://localhost:8501/

 **Project Goal:** To make learning and experimenting with prompt engineering simple, interactive, and beginner-friendly.

##  Features

*  **Multiple Prompting Techniques** — Experiment with six different prompting strategies.
*  **Custom Task Input** — Enter questions, instructions, or other tasks.
*  **Automatic Prompt Generation** — Build a prompt based on the selected technique.
*  **Adjustable Temperature** — Control the response generation setting.
*  **Maximum Token Control** — Set the maximum output token limit.
*  **AI-Generated Responses** — Generate responses using the configured Gemini model.
*  **Generated Prompt Preview** — View the prompt sent to the AI before reading the response.
*  **Error Handling** — Display helpful messages when input is missing or a request fails.
*  **Interactive Web Interface** — Use the application through a Streamlit interface.

##  Prompting Techniques

* **Zero-Shot Prompting:** Generates responses without providing examples.
* **One-Shot Prompting:** Uses one example to guide the AI response.
* **Few-Shot Prompting:** Uses multiple examples to guide the AI response.
* **Chain-of-Thought (CoT):** Encourages a structured approach to solving a task.
* **Manual Chain-of-Thought:** Breaks a task into explicit steps to produce a clear answer.
* **Tree of Thoughts (ToT):** Explores multiple possible approaches and compares them to select a suitable solution.


##  Technologies Used

* **Python** — Application logic and prompt construction.
* **Streamlit** — Interactive web application interface.
* **python-dotenv** — Loading API credentials from environment variables.

## 🖱️ How to Use

1. Launch the Promptora AI application.
2. Select a prompting technique from the dropdown menu.
3. Enter your task in the text area.
4. Adjust the temperature and maximum token settings if needed.
5. Click **Generate Response**.
6. Review the generated prompt.
7. Read the AI-generated response.

###  Example Task

```text

and Machine Learning in simple English with examples.
```
